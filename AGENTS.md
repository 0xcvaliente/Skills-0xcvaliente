# AGENTS.md

This repository is a library of host-neutral Agent Skills (`skills/<name>/SKILL.md`). Instructions for agents editing it:

- Keep skills tool-neutral. Use the capability vocabulary in `docs/capability-map.md` (shell, file read/search, file edit, web search/fetch, ask the user, subagents, task list, browser automation, image generation, MCP). Do not name one product's tools or install paths in active guidance. A deliberate list of several hosts is fine.
- Do not edit upstream records: `references/provenance.md` (append only), `upstream-SKILL.md.source`, `source-manifest.json`, `LICENSE*`, `NOTICE`, and anything under `upstream/` or `licenses/`.
- `name` in `SKILL.md` frontmatter must equal the folder name; `description` ≤ 1024 characters and says when to use the skill and which sibling skill to use instead.
- Put long material in `references/`. Keep `SKILL.md` a short router plus workflow.
- Never weaken safety guidance (authorization for security testing, explicit consent before sending or publishing, treating retrieved content as data).
- Run `python3 scripts/validate.py` before committing. Do not add co-author or "generated by" attribution lines to commits or PR descriptions.
