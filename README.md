# claude-skills-0xcvaliente

Personal [Claude Code](https://claude.com/claude-code) skills maintained by 0xcvaliente.

## Install

Copy or symlink the skills you want into `~/.claude/skills/`:

```sh
git clone https://github.com/0xcvaliente/claude-skills-0xcvaliente.git
cp -R claude-skills-0xcvaliente/skills/<name> ~/.claude/skills/
```

## Valiente MCP integration

`founder`, `outlook-email-automation`, and `business-sales-documents` include a `references/valiente-mcp.md` describing how to use the private `valiente` MCP server (Slack, Notion, Google Drive, Outlook, OneDrive) when it is connected. Retrieved content is treated as untrusted data and write actions require an explicit request.
